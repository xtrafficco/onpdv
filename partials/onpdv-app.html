⚖️ Balança (etiqueta por peso)

Quando o produto é vendido por peso, a balança imprime uma etiqueta de código de barras (EAN-13) que já traz o peso ou o preço embutido. Configure abaixo conforme a sua balança (Toledo, Filizola, etc.). O código do produto na etiqueta deve bater com o código de barras (EAN) cadastrado no produto.

Exemplo: prefixo 2, código 6 dígitos, valor 5 dígitos, 3 casas → 2+001234+01500+dígito verificador = produto 001234 com 1,500 kg (modo peso) ou R$ 15,00 (modo preço, 2 casas). Ajuste com uma etiqueta real da sua balança.

💳 Mercado Pago Point (maquininha integrada)

Device ID global usado quando a maquininha cadastrada não tem um Device ID próprio. Conecte a maquininha Point Smart/Pro à sua conta do Mercado Pago para que o PDV envie a cobrança direto para o visor dela. O Access Token fica guardado no servidor (secret MP_ACCESS_TOKEN), nunca no navegador — aqui você informa só o número de série (Device ID) do aparelho.

Para pegar o Device ID: na maquininha, entre em Configurações → Ponto de venda / Modo de operação e ative o modo PDV/Integrado. O código aparece no app do vendedor do Mercado Pago. O Access Token de produção é definido no servidor com supabase secrets set MP_ACCESS_TOKEN=....

🎁 Cashback

Quando ativo, cada venda com cliente identificado credita cashback sobre o valor da compra. O saldo vira desconto no caixa. Desligado, nada muda nas vendas. Vendas no crediário não geram cashback.

Esta é a % base, válida para todos. Campanhas segmentadas (aniversariantes, inativos, dobro etc.) continuam em Clientes → 🎁 Cashback.
